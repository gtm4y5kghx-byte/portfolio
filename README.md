# Portfolio

Personal portfolio site with CMS-managed content. Projects, work experience, references, and contact form — all driven by Sanity so content updates don't require code changes.

## Tech Stack

- Next.js 16, React 19, TypeScript
- Sanity CMS (headless, with typegen for end-to-end type safety)
- Tailwind CSS 4
- GSAP (scroll-triggered animations, page transitions)
- Resend (contact form email delivery)
- Vitest, Testing Library
- Deployed to Vercel

## Features

- Parallel routes with intercepting routes for overlay-based project detail views
- Scroll-driven reveal animations with reduced motion support
- Reference carousel with auto-advance and GSAP transitions
- Server-side contact form with honeypot spam prevention and rate limiting
